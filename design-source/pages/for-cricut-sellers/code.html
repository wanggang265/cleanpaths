02 · the repair manual

SVG problems, diagnosed

SYMPTOMWhy won't my SVG upload to Cricut Design Space?
Three usual suspects: (1) it's a fake SVG — a bitmap wrapped in SVG tags; (2) it uses unsupported features like embedded fonts or filters; (3) the file is corrupted. CleanPaths outputs true vector paths only, with no embedded bitmaps, so files import cleanly.
SYMPTOMWhy does my SVG show up as a black box in Cricut?
Almost always a raster image hiding inside an SVG wrapper, or fill/stroke settings the importer misreads. The 10-second check: open the file in a text editor and search for <image> — if it's there, you don't have real vector. CleanPaths output is vector paths only; there's nothing in the file that can render as a black box.
SYMPTOMHow do I spot a fake SVG before I waste vinyl on it?
Open it in a text editor: real vector SVGs are lists of paths; fakes contain an <image> tag pointing at a bitmap. Or drop it into CleanPaths — the layer preview shows immediately whether there are real paths to work with.
SYMPTOMGlowforge rejected my SVG over 100 KB — what now?
Glowforge's free tier won't process SVGs above 100 KB. The fix is fewer, cleaner paths: re-trace with a lower precision setting to trade a little smoothness for a much smaller file. Most flat-color designs come out well under the limit.
SYMPTOMHow small can I cut text and still read it?
A working rule from working sellers: keep small text and fine details readable at 1.5–2 inches — below that, simplify. Merge tiny fragments, thicken hairlines, and always test-cut at final size. The Precision Pack's small-size presets automate the simplification step.
