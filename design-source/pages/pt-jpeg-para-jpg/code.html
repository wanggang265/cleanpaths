JPEG e JPG são a mesma coisa

Não existe diferença entre um arquivo .jpeg e um .jpg — nenhuma. As duas extensões apontam para o formato de imagem idêntico, padronizado em 1992 pelo Joint Photographic Experts Group. A versão curta existe apenas porque o Windows antigo exigia extensões de três letras. Então por que esta página existe? Porque muito software continua teimoso: formulários de upload, aplicativos antigos do Windows e sistemas embarcados que aceitam .jpg e rejeitam .jpeg, mesmo sendo exatamente os bytes que pediram.

Por que o mundo de três letras nunca morreu

A extensão .jpg é um fóssil da era DOS, dos nomes de arquivo 8.3 — e sobreviveu à era que a criou. Firmware de dispositivos embarcados, software de quiosque, instalações antigas de CMS, scanners e câmeras mais velhos: uma cauda longa de sistemas ainda procura literalmente por .jpg. Enquanto isso, o macOS e muitas câmeras salvam .jpeg por padrão. O resultado é uma incompatibilidade boba, mas real: o seu arquivo está bom, o sistema de destino está bom, e a única coisa quebrada são quatro letras contra três. Esta página conserta exatamente isso — nada mais, nada menos.

O que significa "reempacotamento sem perda"

Este conversor não decodifica a sua imagem, não a recodifica e não a passa por nenhuma etapa de compressão. Ele verifica se o arquivo é realmente dados JPEG e o devolve com a extensão que o seu sistema espera — os mesmos bytes, os mesmos pixels, a mesma qualidade. É por isso que converter aqui não leva tempo nem custa qualidade: não há nada para recomprimir. Compare com uma conversão "de verdade" (digamos, WebP para JPG), em que os pixels são decodificados e recodificados — legítimo naquele caso, mas desnecessário aqui, porque um JPEG e um JPG já são a mesma coisa.

Quando você realmente precisa desta etapa

Renomear o arquivo por conta própria funciona — .jpeg para .jpg é uma edição de texto no nome do arquivo. Então quando vale um conversor? Quando você não tem certeza de que o arquivo é realmente JPEG por dentro: uma página de erro HTML salva com extensão de imagem não passa na verificação deste conversor. Quando um formulário ou dispositivo rejeitou o seu arquivo e você quer uma cópia limpa e verificada, em vez de um mistério renomeado. E quando você prefere arrastar, soltar e baixar em vez de renomear arquivos um a um — principalmente no celular, onde as extensões ficam escondidas.

FAQ
JPEG é a mesma coisa que JPG?
Sim — completamente. As duas extensões apontam para o formato de imagem idêntico; a curta é uma herança da era dos nomes de arquivo de três letras. Converter entre elas não muda nada na imagem em si, que é exatamente o que o reempacotamento sem perdas desta página faz: extensão nova, mesmo arquivo.
Converter JPEG para JPG perde qualidade?
Não. Este conversor reempacota o seu arquivo sem recodificá-lo — os dados da imagem passam intactos, então não há nova compressão nem perda de qualidade. Os mesmos pixels entram, os mesmos pixels saem. A pré-visualização mostra o resultado antes de você baixar.
Não posso simplesmente renomear o arquivo?
Normalmente, sim — renomear .jpeg para .jpg não muda nada além do nome, e a maioria dos sistemas aceita. Este conversor adiciona duas coisas: ele verifica se o arquivo é realmente dados JPEG antes de devolvê-lo (uma página web salva com extensão de imagem não passa) e mostra uma pré-visualização para você ver o que tem em mãos. Quando a imagem importa — um anúncio, um arquivo de cliente, um trabalho de impressão ou um formulário — uma cópia verificada vale mais que uma esperança renomeada.
Meu arquivo é enviado para algum servidor?
Não. A conversão acontece inteiramente no seu navegador — não existe etapa de upload. Nós não recebemos, não vemos e não armazenamos suas imagens. É assim que a ferramenta é construída, não é só uma frase de marketing. Detalhes na Política de Privacidade.
