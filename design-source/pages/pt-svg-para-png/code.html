Por que converter SVG para PNG?

SVG é o formato certo para ícones, logotipos e ilustrações — até você precisar colocar um deles onde vetor não é falado. Redes sociais, slides, documentos do Word, a maioria dos e-mails e muitos marketplaces querem um bitmap simples. PNG é o bitmap que trata bem a arte vetorial: bordas nítidas, fundo transparente e sem borrões de compressão. Este conversor renderiza o seu SVG para PNG direto no seu navegador — sem upload, e a pré-visualização mostra exatamente o que você vai receber.

O fundo transparente continua transparente

A maior parte da arte SVG flutua sobre o nada — é isso que a torna útil. Convertida sem cuidado, ou capturada em screenshot, ela volta achatada sobre branco ou preto. O PNG suporta um canal alfa completo, então a conversão mantém a sua arte sobre transparência: pronta para cair sobre qualquer cor, slide ou foto de produto sem uma caixa ao redor. JPG não faz isso — se alguém sugerir converter o seu SVG para JPG para a web, aponte a nossa página de SVG para JPG, que explica exatamente o que se perde.

Esta página vai de vetor para pixels. Existe uma página para o caminho inverso.

Converter SVG para PNG rasteriza a sua arte — o resultado parece idêntico, mas não escala mais. Se o que você precisa é o contrário — transformar um bitmap, como uma captura de tela ou a foto de um logotipo, em trajetórias vetoriais limpas e editáveis — isso é outra ferramenta: o nosso conversor de Screenshot para SVG (em inglês) traça bitmaps em vetores em camadas. Rasterizar é o caminho fácil; traçar de volta é o problema difícil, e ele tem as suas próprias páginas.

Vetores não têm pixels — você escolhe o tamanho

Um SVG é um conjunto de instruções de desenho, não uma grade de pontos — por isso, converter para PNG exige uma decisão que nenhum arquivo vetorial toma por você: quantos pixels de largura o resultado deve ter? Renderize pequeno e você tem uma imagem leve para a web. Renderize grande e você tem detalhe que sobrevive à impressão e ao zoom. As opções exatas de tamanho e resolução ficam na ferramenta acima — este texto não trava números que a implementação pode ajustar; a pré-visualização sempre mostra o que as configurações atuais produzem antes do download.

FAQ
Qual será a resolução do PNG?
A escolha é sua, não do arquivo — um vetor não tem tamanho fixo em pixels, então a ferramenta oferece opções de tamanho na conversão. Como regra: avatares e miniaturas para a web pedem pequeno; impressão e detalhe com zoom pedem grande. A pré-visualização mostra exatamente o que a escolha atual produz antes de você baixar.
O PNG terá fundo transparente?
Sim. Se a arte SVG não tem fundo próprio, o canal alfa é preservado — o PNG suporta transparência total. É o principal motivo para escolher PNG em vez de JPG para logotipos e ícones.
Por que meu SVG aparece diferente em alguns aplicativos?
O SVG pode referenciar fontes e efeitos que visualizadores diferentes renderizam de formas diferentes — o arquivo é um conjunto de instruções, e cada aplicativo o interpreta do seu jeito. Converter para PNG congela exatamente o que você vê na pré-visualização em pixels, o que é um motivo prático para converter antes de compartilhar a imagem.
Meu arquivo é enviado para algum servidor?
Não. A conversão acontece inteiramente no seu navegador — não existe etapa de upload. Nós não recebemos, não vemos e não armazenamos suas imagens. É assim que a ferramenta é construída, não é só uma frase de marketing. Detalhes na Política de Privacidade.
