FAQ
Quais conversores posso usar em português?
Os 16 conversores do CleanPaths têm versão em português: 6 convertem imagens para DXF pronto para corte (PNG, JPG, SVG, JPEG, imagem e foto) e 10 resolvem conversões de formato (JFIF, WebP, JPEG, SVG, GIF e BMP). A lista completa está nesta página.
Qual conversor devo usar para gerar um DXF?
Depende do seu arquivo: logo em cores chapadas vai para PNG para DXF; foto de logo vai para JPG para DXF; vetor vai para SVG para DXF; em caso de dúvida, comece por Imagem para DXF. Cada página explica o resultado esperado antes de você converter.
Meus arquivos são enviados para um servidor?
Não. Todas as conversões acontecem no seu navegador — não existe etapa de upload. Nós não recebemos, não vemos e não armazenamos seus arquivos.
Preciso de cadastro para converter?
Não. Sem cadastro: cada conversor é grátis, com 10 conversões por dia.
Existe versão em inglês de cada ferramenta?
Sim — cada conversor tem página equivalente em inglês, acessível pelo link English version no topo e no rodapé de cada página.
